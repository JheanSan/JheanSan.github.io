# Jean Marco Sánchez · Portfolio

**Live:** https://jheansan.github.io

An engineer in five acts, staged as a 1900s Saint Denis theatre: a gas lamp lights, the curtain rises, the cards are dealt, *The Bogotá Gazette* reports SmartCity Bogotá's Best Project award, a cabinet holds the side projects, brass gauges show the languages and a telegram closes the show.

Plain HTML, CSS and JavaScript, with [GSAP](https://gsap.com/) for scroll choreography. Sound effects are synthesised in the browser with the Web Audio API. English and Spanish.
